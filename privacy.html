ระบบนี้คืออะไร

ระบบบันทึกและติดตามงานทะเบียนมะเร็ง เป็นเครื่องมือภายในสำหรับเจ้าหน้าที่ทะเบียนมะเร็งที่ได้รับอนุญาตเท่านั้น ใช้บันทึกผลงาน แนบเอกสาร และสรุปรายงานของทีม

ข้อมูลที่เก็บจากบัญชีผู้ใช้

  • เมื่อเข้าสู่ระบบด้วย Google ระบบได้รับเฉพาะ อีเมล ชื่อ และรูปโปรไฟล์ จาก Google เพื่อยืนยันตัวตน ไม่ได้เข้าถึงอีเมล ไฟล์ หรือข้อมูลอื่นในบัญชี Google
  • เมื่อเข้าสู่ระบบด้วยอีเมลและรหัสผ่าน รหัสผ่านถูกเข้ารหัสโดยผู้ให้บริการยืนยันตัวตน (Supabase Auth) ผู้ดูแลระบบไม่เห็นรหัสผ่าน
  • ชื่อผู้บันทึก วันเวลาที่สร้างและแก้ไข ถูกบันทึกคู่กับงานแต่ละรายการเพื่อระบุผู้รับผิดชอบ

ข้อมูลงานและเอกสาร

  • ข้อมูลงานและเอกสารแนบเก็บในฐานข้อมูลและพื้นที่จัดเก็บแบบส่วนตัวของ Supabase เข้าถึงได้เฉพาะสมาชิกทีมที่ผู้ดูแลระบบอนุญาต
  • เอกสารแนบเปิดด้วยลิงก์ชั่วคราวที่หมดอายุภายใน 60 วินาที
  • ผู้ที่เข้าสู่ระบบแต่ไม่ได้อยู่ในรายชื่อสมาชิกทีม จะไม่เห็นและบันทึกข้อมูลใด ๆ ไม่ได้

การใช้และการเปิดเผยข้อมูล

ข้อมูลใช้เพื่อการปฏิบัติงานทะเบียนมะเร็งของหน่วยงานเท่านั้น ไม่มีการขาย ไม่ใช้เพื่อโฆษณา และไม่เปิดเผยต่อบุคคลภายนอก เว้นแต่เป็นไปตามกฎหมายหรือระเบียบของหน่วยงาน การใช้ข้อมูลที่ได้รับจาก Google API เป็นไปตาม Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use

การเก็บรักษาและการลบข้อมูล

ข้อมูลเก็บรักษาตามระยะเวลาที่หน่วยงานกำหนด เจ้าหน้าที่ที่ต้องการให้ลบบัญชีหรือสอบถามเกี่ยวกับข้อมูลของตน ติดต่อผู้ดูแลระบบได้ทางอีเมลด้านล่าง
